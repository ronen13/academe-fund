# AcadeMe.Fund — שאלון התאמה אישית למלגות וסיוע כלכלי

עמוד שאלון מעוצב (RTL, עברית) בן 6 שלבים, שנבנה מתוך תוכן שאלון ה־Word שסופק.
בסיום מילוי השאלון, כל התשובות נשמרות כשורה חדשה בגיליון **Google Sheets** — ללא צורך בשרת Node נפרד.

הארכיטקטורה פשוטה בכוונה:

```
דפדפן המשתמש  →  (fetch POST)  →  Google Apps Script Web App  →  Google Sheet
```

כלומר: `public/` הוא אתר סטטי טהור (HTML+CSS+JS), שמועלה ל-Render כ-**Static Site**.
השמירה בגיליון מתבצעת ע"י סקריפט קטן שרץ בתוך Google (Apps Script), בלי שרת משלכם.

## מבנה הפרויקט

```
public/
  index.html    → מבנה השאלון (6 שלבים + מסך פתיחה + מסך תודה)
  styles.css    → העיצוב (נאבי כהה + זהב, Frank Ruhl Libre + Assistant)
  script.js     → לוגיקת הוויזארד: ניווט בין שלבים, שדות מותנים, שליחה
  config.js     → כאן מדביקים את כתובת ה-Web App אחרי הפריסה (שלב 2 למטה)
apps-script/
  Code.gs       → הקוד שמדביקים בפרויקט Apps Script כדי לכתוב לגיליון
```

---

## שלב 1 — יצירת גיליון Google Sheets + הדבקת הסקריפט

1. פתחו [sheets.google.com](https://sheets.google.com) וצרו גיליון חדש. אפשר לקרוא לו למשל **"AcadeMe.Fund — תשובות שאלון"**.
2. בתפריט העליון: **תוספים (Extensions) ← Apps Script**. ייפתח עורך קוד בכרטיסייה חדשה, מחובר אוטומטית לגיליון הזה.
3. מחקו את התוכן שכתוב כברירת מחדל בקובץ `Code.gs`, והדביקו במקומו את כל התוכן מתוך `apps-script/Code.gs` שבפרויקט הזה.
4. שמרו (סמל הדיסקט או `Ctrl+S`).
5. **בדיקה מהירה (מומלץ):** מתפריט הפונקציות בראש העורך בחרו `testDoPost_` ולחצו **▶ הרצה (Run)**. בפעם הראשונה Google תבקש הרשאה — אשרו לחשבון שלכם. אחרי ההרצה, חזרו לגיליון ותראו טאב חדש בשם **"תשובות"** עם שורת כותרות ושורת בדיקה אחת. אפשר למחוק את שורת הבדיקה.

## שלב 2 — פריסת הסקריפט כ-Web App וקבלת כתובת URL

1. בעורך ה-Apps Script: **פרוס (Deploy) ← פריסה חדשה (New deployment)**.
2. ליד "בחר סוג" (Select type) לחצו על סמל הגלגל שיניים ובחרו **Web app**.
3. הגדירו:
   - **Execute as:** `Me` (החשבון שלכם — כדי שלסקריפט תהיה גישת כתיבה לגיליון)
   - **Who has access:** `Anyone` (כדי שהדפדפן של המשתמשים באתר יוכל לשלוח נתונים בלי להתחבר עם חשבון Google)
4. לחצו **Deploy**. Google תבקש שוב לאשר הרשאות — אשרו.
5. תקבלו **Web app URL** שנראה כך:
   `https://script.google.com/macros/s/AKfycb.../exec`
   העתיקו את הכתובת הזו.

> **חשוב:** בכל פעם שתעדכנו את הקוד ב-`Code.gs` בעתיד, תצטרכו לבצע **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy** כדי שהשינויים ייכנסו לתוקף בכתובת ה-URL הקיימת.

## שלב 3 — חיבור השאלון לכתובת שקיבלתם

1. פתחו את `public/config.js`.
2. הדביקו את הכתובת שהעתקתם בשלב 2 במקום ה-placeholder:

```js
window.ACADEME_CONFIG = {
  GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/הכתובת_שקיבלתם/exec"
};
```

3. שמרו את הקובץ.

עד שהכתובת לא מוגדרת, השאלון עדיין עובד מקצה לקצה (מציג מסך תודה), אבל רק רושם את הנתונים ל-console של הדפדפן ולא שומר אותם בגיליון — נוח לבדיקה מקומית לפני החיבור.

## שלב 4 — פריסה ל-Render

1. העלו את תיקיית הפרויקט (או לפחות את `public/`) לריפוזיטורי ב-GitHub/GitLab, או לשירות שאתם מחברים ל-Render.
2. ב-[Render Dashboard](https://dashboard.render.com): **New ← Static Site**.
3. חברו את הריפו, והגדירו:
   - **Build Command:** השאירו ריק (אין build — קבצים סטטיים)
   - **Publish directory:** `public`
4. לחצו **Create Static Site**. Render ייתן לכם כתובת ציבורית (וניתן לחבר דומיין מותאם אישית, למשל תת-דומיין תחת `inno-tech.co.il`).

זהו — השאלון חי, וכל שליחה נכתבת כשורה חדשה בגיליון.

## התאמות נפוצות

- **שינוי טקסטים / שאלות:** עורכים ישירות בתוך `public/index.html` — כל שאלה היא בלוק `<div class="field">` עצמאי.
- **הוספת/הסרת עמודה בגיליון:** מוסיפים/מסירים את שם השדה גם במערך `COLUMNS` ב-`apps-script/Code.gs`, וגם בתור `name="..."` בשדה המתאים ב-`index.html`. חשוב לשמור על תיאום בין השניים, אחרת הנתונים ייכתבו לעמודה הלא נכונה.
- **צבעים וגופנים:** כל משתני העיצוב מרוכזים בראש `public/styles.css` תחת `:root` (`--navy-*`, `--gold-*`, `--ivory-*`).

## פרטיות

השאלון כולל שאלות על מידע רגיש (מצב כלכלי, מוגבלות, השתייכות לאוכלוסיות יעד וכו'), בהתאם למקור. כל שדה כזה ניתן לדילוג, ובראש כל שלב רלוונטי מופיעה הבהרה שהמידע משמש להתאמת מלגות בלבד. מומלץ לוודא שגישת העריכה לגיליון Google Sheets מוגבלת לאנשי הצוות הרלוונטיים בלבד (הרשאות שיתוף בגיליון עצמו).
